## 🚀 FLAGSHIP PROJECT: GTMer – Enterprise AI Sales Development SaaS

### 🌟 Platform Overview
**GTMer** is an enterprise-ready, multi-tenant AI SaaS platform that fully automates B2B sales development workflows (SDR) using production-grade **multi-agent orchestration, conversational AI, and asynchronous microservices**.

### ⚡ Key Engineering Highlights:
- 🤖 **Multi-Agent Orchestration**: Designed autonomous multi-agent graphs using **LangGraph** and **AWS Bedrock** for intelligent task routing, decision-making, and dynamic agent role handoffs.
- ✉️ **Autonomous AI SDR Workflows**: Built automated B2B sales pipelines including deep website analysis, real-time lead enrichment, personalized AI email generation, AI voice calling agents, and CRM automation.
- 🔍 **Enterprise RAG & Knowledge Retrieval**: Developed high-accuracy RAG pipelines utilizing embeddings, vector search, and enterprise knowledge stores for context-aware customer interactions.
- 📄 **Intelligent Document Processing (IDP)**: Engineered OCR and LLM-based data extraction systems with AI-assisted validation for automated sales document handling.
- 🏢 **Multi-Tenant SaaS Architecture**: Architected secure multi-tenant infrastructure supporting organization isolation, user role-based permissions, subscription tiers, and granular AI usage tracking.
- ⚡ **High-Performance Async Microservices**: Built **FastAPI microservices** integrated with **PostgreSQL, Redis Streams, Kafka, Docker**, and deployed on **AWS (EC2, Nginx, S3, CloudFront, CI/CD)**.

**Tech Stack:** `Python` `FastAPI` `LangGraph` `OpenClaw` `AWS Bedrock` `RAG` `Kafka` `Redis` `PostgreSQL` `Docker` `AWS` `React`

## 💻 Systems & Hands-On AI Projects

### 🧠 1. AI-Driven Autonomous Test Engineering & Self-Healing Platform (`AITesting_B`)
An end-to-end autonomous software testing engine that analyzes frontend codebases, extracts AST locators via **Tree-Sitter parsers (Java/TypeScript)**, and automatically generates & heals Playwright test cases.
- **Multi-Tier Agent Orchestrator**: Uses `ai_orchestrator_service`, `ai_coverage_agent`, and `ai_fix_service` to automatically diagnose test failures, generate live scripts, dry-run, and apply fallback locator patches automatically.

**Tech Stack:** `Python` `FastAPI` `Tree-Sitter AST` `Playwright` `OpenAI API` `PostgreSQL` `TypeScript`

---

### 🥗 2. Paushtik Aahaar Custom GPT & Agentic RAG Service (`paustika Aahaar`)
A specialized AI domain microservice delivering personalized dietary and nutrition recommendations using **FastAPI** and **ChromaDB** vector store with Custom GPT API integration and automated schema mapping.

**Tech Stack:** `Python` `FastAPI` `ChromaDB` `LangChain` `Docker` `PostgreSQL`

---

### 📊 3. Enterprise LLM Benchmarking Platform & Telegram Bot (`benchmarking`)
An automated benchmark runner evaluating LLM latency, token usage, Exact Match, Word F1, and sandboxed Python execution via **OpenClaw Proxy** with an interactive **Telegram Bot UI** and Matplotlib radar charts.

**Tech Stack:** `Python 3.12` `OpenClaw` `Telegram Bot API` `SQLite` `Matplotlib` `httpx`
