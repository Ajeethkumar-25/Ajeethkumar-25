## 🚀 FLAGSHIP PROJECT: GTMer – Enterprise AI Sales Development Platform

### 🌟 Platform Overview
**GTMer** is an enterprise-ready, multi-tenant AI SaaS platform that fully automates B2B sales development workflows (SDR) using production-grade **multi-agent orchestration, conversational AI, and asynchronous microservices**.

### ⚡ Key Architectural Highlights & Engineering Capabilities:
- 🤖 **Multi-Agent Orchestration**: Designed production-ready autonomous multi-agent graphs using **LangGraph** and **AWS Bedrock** for intelligent task routing, decision-making, and dynamic role handoffs.
- ✉️ **Autonomous AI SDR Workflows**: Engineered automated B2B sales pipelines including deep website analysis, real-time lead enrichment, personalized AI email generation, AI voice calling agents, and CRM automation.
- 🔍 **Enterprise RAG & Knowledge Retrieval**: Developed high-accuracy RAG (Retrieval-Augmented Generation) pipelines utilizing embeddings, vector search, and enterprise knowledge stores for context-aware customer interactions.
- 📄 **Intelligent Document Processing (IDP)**: Built OCR and LLM-based data extraction systems with AI-assisted validation for automated sales document handling.
- 🏢 **Multi-Tenant SaaS Architecture**: Architected secure multi-tenant infrastructure supporting organization isolation, user role-based permissions, subscription tiers, and granular AI usage tracking.
- ⚡ **High-Performance Async Infrastructure**: Built **FastAPI microservices** integrated with **PostgreSQL, Redis Streams, Kafka, Docker**, and deployed on **AWS (EC2, Nginx, S3, CloudFront, CI/CD)**.

**Tech Stack:**  
`Python` `FastAPI` `LangGraph` `OpenClaw` `AWS Bedrock` `RAG` `Kafka` `Redis` `PostgreSQL` `Docker` `AWS` `React`

## 🛠️ Other Key AI Projects & Systems

### 🧠 1. AI-Driven Autonomous Test Engineering Engine (`AITesting_B`)
An autonomous software testing platform that analyzes frontend codebases, extracts AST locators via **Tree-Sitter parsers (Java/TypeScript)**, and automatically generates & heals Playwright test cases.
- Implements self-healing mechanics (`ai_orchestrator_service`, `ai_fix_service`) to automatically patch broken locators and re-run dry-run validations.

**Tech Stack:** `Python` `FastAPI` `Tree-Sitter AST` `Playwright` `OpenAI API` `PostgreSQL`
