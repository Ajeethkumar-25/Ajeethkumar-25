## 🤖 Hands-On AI Projects Developed & Engineered

### 🧠 1. AI-Driven Autonomous Test Engineering & Self-Healing Platform (`AITesting_B`)
An end-to-end autonomous software testing engine that analyzes application UI/frontend code, extracts AST locators via **Tree-Sitter & React semantic extractors**, and automatically generates & heals Playwright test cases.
- **AI Agentic Orchestrator**: Uses a multi-tier agent architecture (`ai_orchestrator_service`, `ai_coverage_agent`, `ai_fix_service`) to automatically diagnose failed test runs and patch locators.
- **AST Code Analysis**: Integrates **Tree-Sitter Java & TypeScript parsers** for deep code introspection, extracting JSX locators, routes, and component trees.
- **Self-Healing Mechanics**: Automatically attempts live script generation, dry-runs, and applies automatic locator fallback fixes when UI elements change.

**Tech Stack:** `Python` `FastAPI` `Tree-Sitter AST` `Playwright` `OpenAI/Claude API` `PostgreSQL` `TypeScript`

---

### 🥗 2. Paushtik Aahaar Custom GPT & Agentic RAG Service (`paustika Aahaar`)
A specialized AI domain backend providing personalized dietary and nutrition recommendations using RAG and vector knowledge retrieval.
- **Agentic AI Microservice**: Built with **FastAPI** and **ChromaDB** vector store for instant retrieval of nutritional, dietary, and customization knowledge bases.
- **Custom GPT Integration**: Interfaces directly with a Custom GPT agent endpoint with automated schema mapping and database synchronization.

**Tech Stack:** `Python` `FastAPI` `ChromaDB` `LangChain` `Docker` `PostgreSQL`

---

### 📊 3. Enterprise LLM Benchmarking Platform & Telegram Bot (`benchmarking`)
An interactive, automated benchmark runner that measures latency, token efficiency, Exact Match, Word F1, and sandboxed code execution across multiple LLMs.
- Connected via **OpenClaw Chat Completions Proxy API** with real-time **Telegram Bot UI** control, live status updates, and dynamic **Matplotlib radar chart visualizations**.

**Tech Stack:** `Python 3.12` `OpenClaw` `Telegram Bot API` `SQLite` `Matplotlib` `httpx`

---

### 💼 4. GTMer – Enterprise AI Sales Development SaaS Platform
A production-grade multi-tenant AI SaaS platform that automates B2B sales workflows through autonomous AI agents, AI email generation, AI voice calling, chatbot automation, lead enrichment, competitor intelligence, and CRM automation.

**Tech Stack:** `Python` `FastAPI` `LangGraph` `AWS Bedrock` `React` `PostgreSQL` `Redis` `Docker` `AWS`
