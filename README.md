## 🚀 Flagship & Core AI Engineering Systems

### 🤖 1. Carry Agent – Cognitive Dual-Engine Autonomous AI Agent
An intelligent autonomous cognitive agent that evaluates, plans, reasons, and self-corrects before executing complex software and engineering tasks.
- **Dual-Engine Context Memory**: Combines **Knowledge Graphs (Neo4j/Concept mapping)** with dynamic **Vector RAG** to understand project context and hidden dependencies.
- **Requirement Clarity & Risk Scoring**: Automatically computes project readiness (0–100 scale), asking clarification questions or negotiating project scope.
- **Multi-Factor Audit & Decision Engine**: Evaluates code security, cost, and architecture risks before execution.
- **Real-Time Self-Correction Loop**: Catches runtime errors and test failures, analyzes error traces, and automatically adjusts approach without manual intervention.

**Tech Stack:** `Python` `LangGraph` `Knowledge Graphs` `ChromaDB` `FastAPI` `Ollama` `Docker`

---

### 💼 2. GTMer – Enterprise AI Sales Development SaaS Platform
A production-grade, multi-tenant AI SaaS platform automating end-to-end B2B sales development through coordinated agent swarms.
- **Multi-Agent Orchestration**: Production **LangGraph + AWS Bedrock** graphs for lead routing, competitor intelligence, and automated outreach.
- **Autonomous SDR Pipelines**: Dynamic website analysis, contact enrichment, personalized AI emails, AI voice calling agents, and CRM sync.
- **Enterprise IDP & RAG**: OCR and LLM-assisted document parsing with automated data validation.
- **Multi-Tenant SaaS Core**: Role-based access control, subscription tiers, and granular AI usage quotas built on **FastAPI, PostgreSQL, Redis Streams, Kafka, and AWS**.

**Tech Stack:** `Python` `FastAPI` `LangGraph` `AWS Bedrock` `RAG` `Kafka` `Redis` `PostgreSQL` `Docker` `AWS`

---

### 🧠 3. AI-Driven Autonomous Test Engineering & Self-Healing Engine (`AITesting_B`)
An end-to-end autonomous quality engineering platform that inspects codebase syntax trees and automatically creates & heals test automation suites.
- **AST Parsing Engine**: Utilizes **Tree-Sitter AST parsers (Java & TypeScript)** and React semantic extractors to discover routes, components, and locators.
- **Self-Healing Agent Network**: `ai_orchestrator_service`, `ai_coverage_agent`, and `ai_fix_service` detect runtime locator drifts, execute live dry-runs, and auto-patch Playwright test scripts.

**Tech Stack:** `Python` `FastAPI` `Tree-Sitter AST` `Playwright` `OpenAI / Claude` `PostgreSQL` `TypeScript`

---
